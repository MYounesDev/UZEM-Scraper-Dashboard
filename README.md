# UZEM Tarama Dashboard

Real-time dashboard that scrapes [Kocaeli University UZEM Edestek](http://edestek.kocaeli.edu.tr/index.php) student data and visualizes course/instructor statistics, with SQLite export.

## Features

- **Concurrent scraping** of student numbers (configurable concurrency, delay, retries)
- **Real-time updates** via Socket.io — stats, logs, and tables stream live to the browser
- **Faculty breakdown** — Engineering (`MUHENDISLIK`) and Science/UZEM (`FEN_UZEM`) tracked separately
- **Sortable, searchable tables** for courses, instructors, and students
- **Drill-down modals** — click a course to see enrolled students, an instructor to see their courses, or a student to see their full course list
- **Start / Pause / Resume / Stop** controls
- **SQLite export** — download the full dataset (students, faculties, instructors, courses, and join tables) as a `.db` file

## Tech Stack

- **Runtime:** Node.js
- **Server:** Express 5 + `http` + Socket.io 4
- **HTML parsing:** jsdom (server-side `DOMParser`)
- **SQLite generation:** sql.js
- **Frontend:** vanilla HTML/CSS/JS (single file, no build step)

## Getting Started

### Prerequisites

- Node.js 18+ (uses global `fetch`)

### Install & Run

```bash
npm install
npm start
```

Then open <http://localhost:3000>.

The port defaults to `3000` and can be overridden with the `PORT` env var:

```bash
PORT=8080 npm start
```

## Usage

1. Open the dashboard in your browser.
2. Click **Baslat** to begin scanning. Student numbers are generated and POSTed to the UZEM Edestek endpoint in batches.
3. Watch live stats update: total requests, valid students found, pending, remaining, and error count.
4. Use the search boxes and sortable column headers to explore courses, instructors, and students.
5. Click any row to open a detail modal.
6. Click **SQL Indir** in the sidebar to download the collected data as a SQLite database.

### Configuration

Tweak these constants in [`dashboard.js`](dashboard.js) to control scraping behavior:

| Constant        | Default | Description                              |
| --------------- | ------- | ---------------------------------------- |
| `CONCURRENCY`   | `100`   | Parallel in-flight requests              |
| `DELAY_MS`      | `150`   | Delay between dispatched requests (ms)   |
| `MAX_RETRIES`   | `2`     | Retry attempts on failed requests        |

Student numbers are generated by `buildOgrnos()` for years 18–25, groups 1–2, up to 180 per group. A known list of valid numbers is also available in [`ogrno.txt`](ogrno.txt).

## API Endpoints

| Method | Path              | Description                                  |
| ------ | ----------------- | -------------------------------------------- |
| `GET`  | `/`               | Serves the dashboard UI                      |
| `GET`  | `/api/students`   | JSON array of all valid students found       |
| `GET`  | `/api/stats`      | JSON snapshot of current scraping stats      |
| `GET`  | `/api/export/db`  | Downloads the dataset as a SQLite `.db` file |

## SQLite Schema

The exported database contains the following tables:

- `faculties` — faculty codes and names
- `instructors` — unique instructor names
- `students` — student number, name, year, group
- `courses` — course key, name, code, faculty, instructor
- `student_faculties` — many-to-many (student ↔ faculty)
- `student_courses` — many-to-many (student ↔ course)
